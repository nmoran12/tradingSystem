# Milestone 5 Plan: Binary Protocol and Feed Handler

**Status:** Not started (planning only)  
**Prerequisite:** Milestones 1–4 complete (56 tests passing)

## Goal

Add a compact binary protocol layer that encodes and decodes `OrderCommand` messages for lower-overhead file and (future) network input—without changing `MatchingEngine` matching semantics.

## Principles

- Protocol is **separate** from `MatchingEngine` (bytes ↔ `OrderCommand` only).
- Keep format **simple and fixed-width** initially (no FIX, no ITCH).
- **Explicit endianness** (document little-endian as canonical).
- **Version field** for forward compatibility.
- **No networking** in Milestone 5.
- CSV replay and CSV engine modes must keep working.

**Goal:** Frozen on-wire layout documented and reviewed before code.

**New files:**

- `docs/BINARY_PROTOCOL.md` — message layout, endianness, version, enum values

**Likely changes:** none to `.cpp` logic yet (optional empty `BinaryProtocol.hpp` with constants only).

**Tests:** none (doc review); optional compile-time `static_assert` on sizes in header

## Protocol sketch (starting point for 5A)

Illustrative only—finalize in `BINARY_PROTOCOL.md`:

| Field | Size | Notes |
|-------|------|--------|
| magic | 4 bytes | e.g. `0x4F424B21` ("OBK!") |
| version | 1 byte | start at 1 |
| msg_type | 1 byte | maps to OrderCommandType |
| side | 1 byte | BUY/SELL |
| order_type | 1 byte | LIMIT/MARKET |
| reserved | 2 bytes | alignment |
| order_id | 8 bytes | uint64 LE |
| price | 8 bytes | int64 LE |
| quantity | 8 bytes | uint64 LE |

Fixed 32-byte message simplifies decoder; variable length deferred.

## Explicitly out of scope (entire milestone)

- FIX, ITCH, SBE industry formats
- Compression, encryption, authentication
- TCP/UDP networking
- Changing match algorithm or `EngineEvent` set
- Custom allocators for encode buffer
- Benchmark optimisation (optional smoke only)

## Risk register

| Risk | Mitigation |
|------|------------|
| Endian bugs on ARM/x86 | Explicit LE helpers + tests on both if available |
| Struct padding differences | Use serialised layout or `static_assert` sizes |
| Accidental API break | No changes to `MatchingEngine::process` signature |
| Scope creep into M6 | No ring buffer in M5 |
